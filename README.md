# 🎨 PrusaSlicer

PrusaSlicer is an **open-source slicer** with **paint-on supports**, **variable layer height**, and **per-object settings**. Its profile editor covers Prusa printers and third-party FDM machines.

- 🖌️ **Paint-on support** strokes
- 📐 **Variable layer height**
- 🧩 **Per-object settings**
- 🎚️ **Profile editor** with overrides
- 🧊 **Layer and seam preview**
- 🧮 **Material and time estimate**
- 🔌 **Custom printer profiles**
- 🗂️ **Config bundles**

## 🚀 Why Choose PrusaSlicer?

Painting supports puts them exactly where overhangs need them instead of everywhere. Variable layer height trades detail for speed on the same model.

Per-object settings let one plate carry parts with different needs.

## 🎮 Why Use It?

- **Place supports** by hand
- **Vary layer height**
- **Tune per object**
- **Build custom profiles**
- **Check seams** in preview

## 🧩 Quick Start

1. Install and add a printer profile.
2. Load a model.
3. Paint supports on overhangs.
4. Set variable layer height.
5. Slice and review the preview.
